# Currency Island

A macOS/iOS-style Dynamic Island for Windows, focused purely on CBR (Bank of Russia) exchange rates.

## Features

- Live USD/EUR/CNY rates with a 3-day history table
- Interactive 5-day trend chart with smooth curves and gradient fill
- Two hover styles: boxed tooltip or crosshair chips (switchable in settings)
- Real OS-window resize on tab switch
- Launch with Windows (self-healing autostart)
- Self-updating from GitHub releases

## Build

```
dotnet publish -c Release
```
